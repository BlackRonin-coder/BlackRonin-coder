# Bindu

Bindu is a system-repair and optimization method created by **Leon Maurice Browne**.

It is designed to diagnose structural failure, identify the true constraint, redesign the system around aligned incentives and correction loops, and keep the result honest through proof, boundaries, and governance.

## Current public frameworks
- [BINDU MEDICAL — MDCE](https://github.com/leonbrowne/bindu-medical-mdce)
- [STERLING–HOME Framework](https://github.com/leonbrowne/sterling-home-framework)
- [BINDU ATM](https://github.com/leonbrowne/bindu-atm)

## What Bindu does
- maps the real system rather than the claimed one
- finds the binding constraint
- aligns rules, incentives, verification, and correction
- separates structural validity from proof maturity
- prefers survivable design over elegant collapse

## Current status
Bindu is currently presented as a governed architecture moving toward productized, pilot-proven use.

## Working principle
Do not merely describe a broken system.  
Show what is failing, why it is failing, what should replace it, how to test the fix safely, and how to stop it drifting back.
